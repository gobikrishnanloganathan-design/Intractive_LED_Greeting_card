#    HIGH VOLTAGE

## 1\.DESCRIPTION

*  **Designed a simple greeting card for expressing warm wishes and encouragement.**

## 2\.PROCEDURE

* **Take a chart paper and fold it into a greeting card.**  
* **Place a CMOS battery inside the card.**  
* **Fix an LED using aluminium foil behind the flower.**  
* **Connect the LED, battery and push button using thin wires.**  
* **Cover the circuit with paper and decorate the card.**  
* **Press the ”PRESS HERE” area to make the LED glow.**

## 3.WORKING

## COMPONENTS USED

* **coloured paper**  
* **CMOS battery**  
* **aluminium foil**  
* **tap**  
* **glue**  
* **LED**
